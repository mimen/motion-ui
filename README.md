# motion-ui

Built output of the AUF motion UI galleries, served at https://mimen.github.io/motion-ui/.

- `site/` is the web gallery; `site/native/` is the Expo gallery's web export.
- The source lives in the private AUF monorepo (`packages/ui-*`, `apps/ui-gallery*`). Its
  `ui-gallery-publish` workflow replaces this repository's contents on every change. Do not edit here.
